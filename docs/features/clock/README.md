# Clock

| Field | Value |
|---|---|
| Identifier | `CLK` |
| Status | Approved |

## Description

Show the current time and date clearly on the ambient dashboard so the user can understand the current moment at a glance.

## Scope

- Current time in the dashboard’s configured location timezone
- Today’s date with a readable weekday and date
- 24-hour time display
- A readable date format such as “Monday, 5 October”
- Keeping the displayed time and date current while the dashboard is open
- The clock and date as a visible dashboard element

## Stories

- [CLK-001 — Show the current time and date](./CLK-001-show-current-time-and-date.md)

## Out of scope

- Alarm, timer, stopwatch, or countdown functionality
- Timezone configuration or location management
- Calendar events or reminders
- Multiple clocks for different timezones
