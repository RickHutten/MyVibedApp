# Weather

| Field | Value |
|---|---|
| Identifier | `WEA` |
| Status | Proposed |

## Description

Provide useful weather information at a glance so the dashboard user can understand the conditions relevant to their current location.

## Scope

- Current weather conditions
- Location input for weather requests
- Visual representations of weather conditions
- Forecasts and weather-based recommendations may be added through later stories
