# Schedule and Commute

| Field | Value |
|---|---|
| Identifier | `SCH` |
| Status | Proposed |

## Description

A configurable work schedule that tells the dashboard where the user needs to be and provides proactive outbound public-transport commute information.

## Scope

- Configurable weekly work patterns, recurring rules, date ranges, and one-off overrides
- Work-from-home days and office locations
- Today and next-working-day commute planning
- Wake-up and departure recommendations
- Public-transport disruptions and periodic commute refreshes
