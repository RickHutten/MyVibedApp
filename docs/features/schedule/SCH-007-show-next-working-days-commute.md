# SCH-007: Show the next working day’s commute

| Field | Value |
|---|---|
| Status | Draft |
| Priority | To be decided |

## Description

As a user, I want to see tomorrow’s outbound commute in advance so that I know when to wake up and leave the house.

## Scope

- **In scope:**
  - Next working day’s location
  - Wake-up time
  - Departure time
  - Public-transport route and direction
  - Display from 12:00 local time
- **Out of scope:**
  - Return commute
  - Calendar integration

## Acceptance criteria

- [ ] From 12:00 local time, the dashboard shows the next working day’s resolved location.
- [ ] For an office day, the dashboard shows wake-up and departure times.
- [ ] For an office day, the dashboard shows the outbound public-transport route.
- [ ] For a work-from-home or non-working day, the dashboard shows no commute information.
