# SCH-005: Configure commute preferences

| Field | Value |
|---|---|
| Status | Draft |
| Priority | To be decided |

## Description

As a user, I want to configure the locations and wake-up preference used for commute planning so that the recommendations fit my routine.

## Scope

- **In scope:**
  - Home location
  - Office locations
  - Configurable wake-up lead time
  - A default wake-up lead time of 45 minutes before departure
- **Out of scope:**
  - Return commute planning
  - Calendar integration

## Acceptance criteria

- [ ] The user can configure the home location.
- [ ] The user can configure office locations.
- [ ] The user can change the wake-up lead time.
- [ ] The default wake-up lead time is 45 minutes.

## Dependencies

- **Blocked by:** [SCH-004](./SCH-004-resolve-upcoming-work-locations.md)
- **Related:** None
