# SCH-006: Show today’s outbound commute

| Field | Value |
|---|---|
| Status | Draft |
| Priority | To be decided |

## Description

As a user, I want to see how to get to today’s office so that I know when to wake up and leave home.

## Scope

- **In scope:**
  - Outbound commute only
  - Wake-up time
  - Departure time
  - Public-transport route and direction
  - Transport line and service details
- **Out of scope:**
  - Return commute
  - Next-working-day commute
  - Calendar integration

## Acceptance criteria

- [ ] The dashboard shows an outbound commute on an office day.
- [ ] The dashboard shows the recommended wake-up time.
- [ ] The dashboard shows a departure time and route instruction.
- [ ] The dashboard shows no commute information on a work-from-home or non-working day.

## Dependencies

- **Blocked by:** [SCH-005](./SCH-005-configure-commute-preferences.md)
- **Related:** None

## Notes

- Example wording: “Take bus 34 at 07:25 towards Central Station.”
